# M3.1: Enhanced Import Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete the playlist import workflow by adding playlist creation, resumable imports for large playlists, interactive review mode for low-confidence matches, and user-provided override files.

**Architecture:** M3.1 builds on M3's matching engine and import infrastructure. It adds three new capabilities: (1) actual playlist creation on the target provider using provider APIs; (2) state checkpointing to resume interrupted imports (for quota/rate-limit scenarios); (3) interactive mode where users review and approve low-confidence matches before creating the playlist; (4) override files to allow users to manually correct or provide matches for unmatched tracks. All changes are additive—existing `sple import` behavior is preserved; new features are opt-in via flags (`--review`, `--resume`, `--overrides`).

**Tech Stack:** TypeScript, Node.js 20+ LTS, ESM, existing provider APIs, state serialization (JSON), interactive stdin prompts.

**Spec:** This plan implements the deferred scope from M3 (FR-MIG-3 interactive review, FR-MIG-4 resumability) plus playlist creation. It builds on M3's MatchingEngine, CanonicalFileReader, MatchReportWriter, and provider interfaces.

## Review Focus

These five scenarios are most likely to silently break or frustrate users:

1. **User starts a 1000-track import, hits quota at track 437, and must restart.** Without resumability, re-running import restarts from track 1, wasting quota and time. State manager must checkpoint every N matched tracks (e.g., 50) to a persistent file; `--resume` must detect and load that checkpoint.

2. **Low-confidence match (0.45 confidence) is wrong, or right but excluded.** Without `--review`, low-confidence matches are never added (Task M3.1-1). Interactive mode must show the low-confidence match with the source and candidate side-by-side, allow the user to reject it, and record that decision so re-runs respect it.

3. **User has 5 unmatched tracks, manually finds the correct tracks on target provider, and wants to provide those IDs.** Override file must accept a simple format (track position + target ref), merge overrides with auto-matched results, and report how many were overridden.

4. **Playlist creation fails partway through (e.g., permission denied on track 50 of 100).** Import must report which tracks were added before the failure, save that state, and allow user to retry or skip failed tracks on resume. As of Task M3.1-1 the CLI names the created playlist and exits with the provider error's code, but cannot say how many tracks were added: `populatePlaylist` reports nothing when it throws. Task M3.1-2 must close this gap (see its Step 6).

5. **Two low-confidence matches point to the same target track (collision).** Interactive mode must flag the collision, show both source tracks and the single target match, and ask user to choose one or skip both.

Each scenario has an explicit test case in the owning task below.

**Decisions (from code review of the first implementation):**
- **Only `matched` tracks are added.** `low-confidence` means below `--min-confidence`; adding them made the flag meaningless. They are skipped and the CLI prints `N low-confidence match(es) skipped (below --min-confidence X)`. Task M3.1-3 (`--review`) is how a user opts them back in.
- **Provider errors are not wrapped.** If `createPlaylist` throws a `ProviderError` (e.g. `AuthRequiredError` for a missing write scope, `QuotaExhaustedError`), it propagates unchanged so `cli.ts` reports the right exit code (3/5) and hint. Only non-provider errors become `PlaylistCreationError` (with `cause`).
- **A failed add names the orphaned playlist.** If `populatePlaylist` throws, the creator throws `PlaylistAddTracksError(message, playlistId, playlistUrl, { cause })`. The CLI prints `sple: playlist <url|id> was created, but adding tracks failed` and rethrows `cause`, so exit code and message come from the provider error. No `added`/`failed` counts: `populatePlaylist` does not report progress when it throws, so any count would be invented (see Task M3.1-2).
- **Per-track rejections are a partial failure (ADR 0007 §5).** Each failure is listed (`✗ <ref>: <error>`), followed by `sple: added X of N tracks; Y failed (see above)`, exit 1, and a `PartialFailure` ErrorOutput with `--json`.
- The import command no longer wraps every error in `UsageError` (that turned auth/quota errors into exit 2).

```typescript
import { writeFile, readFile, unlink } from 'fs/promises';
import { mkdir } from 'fs/promises';
import { dirname } from 'path';
import { createHash } from 'crypto';
import { ImportCheckpoint, CheckpointStorage } from './import-state.js';
import { MatchResult } from '../matching/types.js';

export class StateManager implements CheckpointStorage {
  async saveCheckpoint(checkpoint: ImportCheckpoint, filepath: string): Promise<void> {
    const dir = dirname(filepath);
    await mkdir(dir, { recursive: true });
    await writeFile(filepath, JSON.stringify(checkpoint, null, 2), 'utf-8');
  }

  async loadCheckpoint(filepath: string): Promise<ImportCheckpoint | null> {
    try {
      const content = await readFile(filepath, 'utf-8');
      const checkpoint = JSON.parse(content) as ImportCheckpoint;

      if (checkpoint.version !== 1) {
        throw new Error(`Unsupported checkpoint version: ${checkpoint.version}`);
      }

      return checkpoint;
    } catch (error) {
      if (error instanceof Error && error.message.includes('ENOENT')) {
        return null;
      }
      throw error;
    }
  }

  async delete(filepath: string): Promise<void> {
    try {
      await unlink(filepath);
    } catch (error) {
      if (error instanceof Error && !error.message.includes('ENOENT')) {
        throw error;
      }
    }
  }

  async isResumable(filepath: string, expectedSourceHash: string): Promise<boolean> {
    const checkpoint = await this.loadCheckpoint(filepath);
    if (!checkpoint) return false;
    if (checkpoint.state !== 'in-progress') return false;
    if (checkpoint.sourceFile.hash !== expectedSourceHash) return false;
    return true;
  }

  mergeResults(
    checkpoint: ImportCheckpoint,
    newResults: MatchResult[],
    newProcessedCount: number
  ): ImportCheckpoint {
    const merged = { ...checkpoint };
    merged.results = [...checkpoint.results, ...newResults];
    merged.processedCount = newProcessedCount;

    // Recalculate metadata
    const metadata = { totalTracks: checkpoint.metadata.totalTracks, matched: 0, lowConfidence: 0, unmatched: 0, unsupported: 0 };
    for (const result of merged.results) {
      if (result.status === 'matched') metadata.matched++;
      if (result.status === 'low-confidence') metadata.lowConfidence++;
      if (result.status === 'unmatched') metadata.unmatched++;
      if (result.status === 'unsupported') metadata.unsupported++;
    }
    merged.metadata = metadata;

    return merged;
  }

  computeFileHash(content: Buffer): string {
    return createHash('sha256').update(content).digest('hex');
  }
}
```

Create `src/cli/interactive-review.ts`:

```typescript
import * as readline from 'readline';
import { MatchReport, MatchResult } from '../core/matching/types.js';

export interface UserDecision {
  position: number;
  decision: 'approve' | 'reject' | 'override' | 'skip';
  overrideRef?: string;
}

export interface CollisionInfo {
  targetRef: string;
  sourceTracks: { position: number; title: string }[];
}

export class InteractiveReview {
  private rl: readline.Interface | null = null;

  getLowConfidenceMatches(report: MatchReport): MatchResult[] {
    return report.results.filter(r => r.status === 'low-confidence');
  }

  detectCollisions(report: MatchReport): CollisionInfo[] {
    const targetMap = new Map<string, { position: number; title: string }[]>();

    for (const result of report.results) {
      if (result.candidate?.trackRef) {
        const ref = result.candidate.trackRef;
        if (!targetMap.has(ref)) {
          targetMap.set(ref, []);
        }
        targetMap.get(ref)!.push({ position: result.position, title: result.track.title });
      }
    }

    return Array.from(targetMap.entries())
      .filter(([_, sources]) => sources.length > 1)
      .map(([ref, sources]) => ({ targetRef: ref, sourceTracks: sources }));
  }

  formatMatchForReview(result: MatchResult): string {
    const source = `${result.track.title} by ${result.track.artists.join(', ')}`;
    const target = result.candidate
      ? `${result.candidate.metadata?.title || result.candidate.trackRef}`
      : 'No match';
    const confidence = result.confidence
      ? `${Math.round(result.confidence * 100)}%`
      : 'N/A';

    return `
Track ${result.position}: ${source}
  ↓ Suggested match: ${target}
  Confidence: ${confidence}
    [a]pprove | [r]eject | [o]verride | [s]kip
    `;
  }

  applyUserDecision(report: MatchReport, decision: UserDecision): MatchReport {
    const result = report.results.find(r => r.position === decision.position);
    if (!result) return report;

    const updated = { ...report };
    updated.results = report.results.map(r => {
      if (r.position !== decision.position) return r;

      const updatedResult = { ...r };

      if (decision.decision === 'approve') {
        // No change, already matched
        (updatedResult as any).userDecision = 'approved';
      } else if (decision.decision === 'reject') {
        updatedResult.status = 'unmatched';
        updatedResult.candidate = undefined;
        (updatedResult as any).userDecision = 'rejected';
      } else if (decision.decision === 'override' && decision.overrideRef) {
        updatedResult.status = 'matched';
        updatedResult.candidate = { trackRef: decision.overrideRef, confidence: 1.0, metadata: {} };
        (updatedResult as any).userDecision = 'overridden';
      } else if (decision.decision === 'skip') {
        (updatedResult as any).userDecision = 'skipped';
      }

      return updatedResult;
    });

    return updated;
  }

  async promptUser(message: string): Promise<string> {
    if (!this.rl) {
      this.rl = readline.createInterface({
        input: process.stdin,
        output: process.stdout
      });
    }

    return new Promise((resolve) => {
      this.rl!.question(message, (answer) => {
        resolve(answer.trim().toLowerCase());
      });
    });
  }

  async reviewLowConfidenceMatches(report: MatchReport): Promise<MatchReport> {
    const lowConf = this.getLowConfidenceMatches(report);
    if (lowConf.length === 0) {
      console.log('No low-confidence matches to review.');
      return report;
    }

    console.log(`\n--- Interactive Review (${lowConf.length} low-confidence matches) ---\n`);

    let updated = report;
    for (const match of lowConf) {
      console.log(this.formatMatchForReview(match));
      const input = await this.promptUser('Your choice: ');

      let decision: UserDecision;
      if (input === 'a') {
        decision = { position: match.position, decision: 'approve' };
      } else if (input === 'r') {
        decision = { position: match.position, decision: 'reject' };
      } else if (input === 'o') {
        const ref = await this.promptUser('Enter target track ref: ');
        decision = { position: match.position, decision: 'override', overrideRef: ref };
      } else {
        decision = { position: match.position, decision: 'skip' };
      }

      updated = this.applyUserDecision(updated, decision);
    }

    if (this.rl) {
      this.rl.close();
      this.rl = null;
    }

    return updated;
  }
}
```

```typescript
import { readFile } from 'fs/promises';
import { MatchResult } from '../matching/types.js';

export interface Override {
  position: number;
  targetRef: string;
}

export class OverrideFileReader {
  async readFile(filepath: string): Promise<Override[]> {
    const content = await readFile(filepath, 'utf-8');
    let data;

    try {
      data = JSON.parse(content);
    } catch {
      throw new Error(`Invalid JSON in override file: ${filepath}`);
    }

    if (!Array.isArray(data)) {
      throw new Error('Invalid override file format: expected array of overrides');
    }

    for (const item of data) {
      if (typeof item.position !== 'number' || typeof item.targetRef !== 'string') {
        throw new Error('Invalid override format: each entry must have position (number) and targetRef (string)');
      }
    }

    return data as Override[];
  }

  mergeOverrides(results: MatchResult[], overrides: Override[]): MatchResult[] {
    return results.map(result => {
      const override = overrides.find(o => o.position === result.position);
      if (!override) return result;

      if (result.position < 1 || result.position > results.length) {
        throw new Error(`Invalid position in override: ${result.position}`);
      }

      return {
        ...result,
        status: 'matched' as const,
        candidate: {
          trackRef: override.targetRef,
          confidence: 1.0,
          metadata: {
            title: result.track.title,
            artists: result.track.artists,
            duration: result.track.duration
          }
        },
        userDecision: 'overridden'
      };
    });
  }
}
```
